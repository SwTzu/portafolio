# Portafolio de Benjamin Morales Carvajal

Portafolio profesional construido con React, TypeScript, Vite y Bun. Muestra una seleccion cerrada de repositorios para presentar experiencia academica, frontend, backend, mobile y full stack.

## Desarrollo

```bash
bun install
bun run dev
```

## Build

```bash
bun run build
```

## Editar datos

Los datos de perfil y proyectos estan en `src/data/projects.ts`.

- Actualiza `profile.linkedin` y `profile.email` con tus datos reales.
- Ajusta resumen, stack o estado de cada proyecto si quieres afinar la presentacion.
