## English

### Overview

This repository is the public showcase of my selected work across frontend, backend, mobile, and full-stack projects.

It is designed to help recruiters and technical reviewers understand what I built, where I contributed, and what kind of problems I have worked on without needing to inspect several repositories first.

### What I built

- A curated portfolio that turns project history into recruiter-friendly case studies across academic, operational, and product-focused work.
- A bilingual presentation layer backed by `src/data/projects.ts`, where each project includes context, responsibilities, contribution, technical highlights, and impact.
- A lightweight React + Vite experience that presents selected repositories as one coherent professional story instead of isolated code snapshots.

### My role and impact

- I structured the portfolio around the work I can explain best: product-facing frontend, backend services, integrations, technical documentation, validation flows, and mobile support for field operations.
- I condensed each project into clear signals that matter in a first review: project type, stack, contribution, and practical outcome.
- I used one repository to connect collaborative and personal work across university, operational, and production-like contexts.

### Selected work

- **Seminario** (`Tesis`, Next.js, Express, Sequelize, MySQL, JWT, Python): clarified and documented an end-to-end clinical and academic platform with API flows, authentication, image handling, and PWAT processing.
- **InnovoBack** (`Backend`, Express, MongoDB, Socket.io, Firebase, Excel): operational backend for assignments, routes, notifications, data management, and Gmail/XLS automation.
- **InnovoFront** (`Frontend`, Next.js, HeroUI, Tailwind, Leaflet, Charts): web dashboard for operational visibility with maps, tables, KPIs, filters, and reports.
- **appInnovo** (`Mobile`, Expo, React Native, Expo Router, Maps, Camera): mobile field app for routes, location, camera usage, notifications, and operational follow-up.
- **Pinf** (`Full stack`, Next.js, Express, Sequelize, MySQL, JWT): collaborative university system for practice management with separate frontend and backend layers.
- **claims_platform Backend** (`Backend`, Bun, TypeScript, Express, Sequelize, MySQL): complaint-management API with JWT, RBAC, auditing, migrations, and resolution workflows.
- **claims_platform Frontend** (`Frontend`, Next.js, HeroUI, Tailwind, Forms): public-facing complaint intake and tracking experience focused on clarity, trust, and guided user flows.

### Tech focus

- Frontend: React, TypeScript, Next.js, Vite, Tailwind, HeroUI
- Backend: Bun, Express, Node.js, JWT, Socket.io
- Data: MySQL, Sequelize, MongoDB, Mongoose
- Mobile and integrations: Expo, React Native, Firebase, Gmail automation, Python scripts

```bash

bun run build
bun run preview
```

## Espanol

### Resumen

Este repositorio es la vitrina publica de mi trabajo seleccionado en proyectos frontend, backend, mobile y full stack.

Esta pensado para que reclutadores y revisores tecnicos entiendan que construi, donde aporte y que tipo de problemas he trabajado sin tener que revisar varios repositorios antes.

### Que construi

- Un portafolio curado que transforma historial de proyectos en casos de estudio faciles de leer para procesos de seleccion tecnica.
- Una capa de presentacion bilingue respaldada por `src/data/projects.ts`, donde cada proyecto incluye contexto, responsabilidades, contribucion, aspectos tecnicos e impacto.
- Una experiencia ligera en React + Vite que presenta repositorios seleccionados como una historia profesional coherente y no como codigo aislado.

### Mi rol e impacto

- Organice el portafolio alrededor del trabajo que puedo explicar con mayor claridad: frontend orientado a producto, servicios backend, integraciones, documentacion tecnica, validacion de flujos y soporte movil para operaciones en terreno.
- Sintetice cada proyecto en senales utiles para una primera revision: tipo de proyecto, stack, contribucion y resultado practico.
- Use un solo repositorio para conectar trabajo colaborativo y personal en contextos universitarios, operacionales y cercanos a produccion.

### Proyectos destacados

- **Seminario** (`Tesis`, Next.js, Express, Sequelize, MySQL, JWT, Python): ordena y documenta una plataforma clinica y academica end-to-end con API, autenticacion, manejo de imagenes y procesamiento PWAT.

- **InnovoFront** (`Frontend`, Next.js, HeroUI, Tailwind, Leaflet, Charts): panel web para supervisar operacion con mapas, tablas, KPIs, filtros y reportes.
- **appInnovo** (`Mobile`, Expo, React Native, Expo Router, Maps, Camera): aplicacion movil para trabajo en terreno con rutas, ubicacion, camara, notificaciones y seguimiento operativo.
- **Pinf** (`Full stack`, Next.js, Express, Sequelize, MySQL, JWT): sistema universitario colaborativo para gestionar practicas con frontend y backend separados.
- **claims_platform Backend** (`Backend`, Bun, TypeScript, Express, Sequelize, MySQL): API para canal de denuncias con JWT, RBAC, auditoria, migraciones y flujo de resolucion.
- **claims_platform Frontend** (`Frontend`, Next.js, HeroUI, Tailwind, Forms): experiencia web publica para ingresar y seguir denuncias con foco en claridad, confianza y acompanamiento del usuario.
